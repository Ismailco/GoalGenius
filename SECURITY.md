# Security policy

## Supported versions

Rungset is currently a beta project. Security fixes are prioritized for the
latest `main` branch and the latest published beta release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
`contact@ismailcourr.dev` with:

- A short description of the issue and its potential impact
- The affected commit, release, route, or component
- Reproduction steps or a minimal proof of concept
- Any logs or screenshots needed to understand the report, with secrets and
  personal data removed

Please do not include passwords, API tokens, private workspace content, or
other credentials in the report.

We will acknowledge a report when practical, investigate its impact, and
coordinate a fix or mitigation before public disclosure when appropriate.
